Lexy’s ABC Sound Game — 30 заданий

Папка lexy-abc содержит готовую отдельную игру для GitHub Pages.
Загрузите содержимое этой папки в новую папку lexy-abc в существующем репозитории. ZIP предварительно распакуйте. Старую игру заменять не нужно.
Адрес новой игры — адрес сайта репозитория с добавлением /lexy-abc/.
Для локальной проверки можно открыть index.html в браузере. Для автономного открытия одним файлом используйте отдельно предоставленный Lexy_ABC_30_offline.html.

Состав: 30 заданий, 20 слов; Aa, Bb, Cc по 10 раз. При запуске порядок перемешивается.
Ответы соответствуют согласованной таблице: 18 ✓, 12 ✗.
До выбора слова не написаны. Кнопки доступны после окончания аудио.
Ошибочный ответ: исходный сигнал и повтор слова. Правильный: исходный звон и переход.
Вступление и финал из записи пользователя. Голос сохранён без изменения.
Кнопка Listen повторяет запись. Стрелка служит резервным переходом после правильного ответа.
Если браузер остановил звук, нажмите Listen.

Размещение на GitHub Pages даёт обычную публичную ссылку. Доступность без VPN необходимо проверить на телефоне.
При открытии по HTTPS игра сохраняет ресурсы для следующих автономных запусков после успешной полной загрузки. Очистка данных браузера удаляет сохранённые ресурсы.

Проверка: все 30 раундов, соответствие файлов картинкам/словам, повтор после ошибки, повтор звука, защита от двойного нажатия, автоматический и резервный переход, завершение и повторный запуск.
Проверка в настоящем мобильном браузере остаётся за пользователем.
