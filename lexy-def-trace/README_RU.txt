Lexy Trace D–E–F

Сначала ребёнок обводит D, d, E, e, F, f по зелёной точке и стрелке.
Затем слушает слово, выбирает Dd / Ee / Ff и обводит обе буквы.
Слова: dirty, desk, drum, duck, egg, elephant, fast, farm, fork, floor.
Порядок слов меняется при новом прохождении.
Кнопка Listen повторяет слово; ↺ очищает текущую букву.
В конце: Well done! You can play again! и мыльные пузырьки, которые можно лопать.

Озвучка слов и финала взята из присланных записей. Компьютерного синтеза речи нет.
Команды Trace the letter / Listen. Choose the letter показаны текстом.
Обводка выполняется пальцем, стилусом или мышкой, начиная с зелёной точки.

Загрузка на GitHub:
1. Распакуйте ZIP.
2. Откройте корень репозитория Lexy.
3. Add file → Upload files.
4. Перетащите папку lexy-def-trace целиком. Пути должны начинаться с lexy-def-trace/.
5. Commit changes.
После успешной публикации адрес: https://tvmisst.github.io/Lexy/lexy-def-trace/
Старые игры лежат в других папках; их файлы заменять не нужно.
